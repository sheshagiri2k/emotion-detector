# Emotion Detector AI Application

An AI-powered web application that analyzes textual input to detect and categorize underlying human emotions (e.g., Joy, Sadness, Anger, Fear, Surprise). Built using Python, Flask for the backend API, and integrated with advanced Natural Language Processing (NLP) libraries.

---

## 🚀 Features
* **Real-time Text Analysis:** Instantaneous parsing of sentences or paragraphs to extract emotional sentiments.
* **Granular Emotion Scores:** Outputs a comprehensive breakdown of emotion confidence metrics (percentages/decimals).
* **Dominant Emotion Identification:** Automatically highlights the primary emotion detected in the text body.
* **RESTful API Architecture:** Easy-to-integrate JSON endpoints for external client applications.
* **Clean UI/Static Frontend:** Minimalist web dashboard for direct user interaction.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Backend Framework:** Flask
* **AI/NLP Engine:** Watson NLP / Hugging Face Transformers / `watson_nlp` library interface
* **Testing & Tools:** Unittest, cURL
